# Atlas — A Spatial Journal

> *A hand-drawn map of places that existed mostly in the mind.*

A scroll-driven spatial journal with a live WebGL canvas layer. Paper-textured, typographically rich, zero dependencies — single HTML file.

---

## What it is

Atlas is an editorial web experience that pairs scroll-activated chapters with a reactive 3D canvas. Each entry reads like a journal page from an explorer who isn't entirely sure the places they're describing are real.

---

## Features

- **WebGL canvas layer** — live scene rendering behind the paper content
- **Paper grain overlay** — SVG fractal noise via CSS, multiply blended for an analogue feel
- **Scroll-driven chapters** — sections activate as you move through the journal
- **Progress rail** — right-side dot navigator with chapter labels
- **Typography** — Fraunces (variable optical-size serif) + JetBrains Mono
- **Palette** — warm paper tones, ember accent, sage and mist secondaries
- **Fixed chrome** — logo mark + nav, mix-blend-mode multiplied into the content

---

## Stack

```
HTML · CSS · Vanilla JS · WebGL
Fonts: Fraunces · JetBrains Mono (Google Fonts)
```

No build step. Open `Atlas spatial journal.html` directly in a browser.
